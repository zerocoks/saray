# Сайт ресторана «Сарай»

Astro 5, статическая сборка + небольшой PHP-бэкенд для заказов и брони (Telegram).

## Запуск
```
npm install
npm run dev        # разработка (корзина и заказ в dev не отправятся — нужен PHP)
npm run build      # готовый сайт в dist/
```

## Заказы и бронь в Telegram
1. В `@BotFather` создайте бота, скопируйте токен. Напишите боту любое сообщение (или добавьте его в группу).
2. Узнайте `chat_id`: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`.
3. На сервере, в папке `api/` рядом с `order.php`, создайте `config.php` по образцу `config.example.php` и впишите токен и chat_id.
   **Токен не кладите в git и не отправляйте в чаты.** Если он утёк — `/revoke` в BotFather.
4. Нужен хостинг с PHP 8.1+ (расширение curl желательно). Заливайте содержимое `dist/` в корень сайта.

Как это работает: корзина живёт в браузере, на сервер уходят только ключи блюд и количество. `api/order.php`
сам пересчитывает сумму по `api/menu.json` (его создаёт сборка), поэтому подменить цену с телефона нельзя.

## Что настраивать
- `src/data/menu.json` — меню. Позиция с выбором (вкус, объём) — поле `prices: [{vol, price}]`.
  Ключи блюд в корзине зависят от порядка позиций, поэтому после правок меню делайте новую сборку.
- `src/data/delivery.json` — минимальная сумма заказа, стоимость доставки, бесплатная доставка от суммы,
  способы оплаты и текст про доставку. Сейчас стоят нули и текст «стоимость подтвердит администратор».
- `src/data/promos.json` — акции на главной.
- В `menu.json` флаг `"hit": true` показывает метку «ХИТ», `"new": true` — «NEW».

## Фото и наполнение главной
Все фото сейчас — плейсхолдеры с подписью «ФОТО…» прямо на картинке. Заменяйте файлы в `public/img/` тем же именем
и размером (WebP, качество ~80):

| Файл | Где | Размер |
|---|---|---|
| `hero.webp` | главный экран: интерьер или блюдо | 1920×1080 |
| `dish.webp` | общее фото для хитов без своего фото | 800×600 |
| `atmosphere-1…5.webp` | «Атмосфера»: зал, огонь, стол, детали, блюдо | 1000×1250, 1200×800, 800×800, 1200×800, 800×1000 |
| `promo.webp` | акции без своего фото | 800×600 |

- Фото блюда: в `menu.json` у позиции поле `"photo": "/img/dishes/plov.webp"` (800×600, 4:3).
- Хиты на главной — позиции с `"hit": true` (первые 6).
- Акции: `src/data/promos.json`, поля `photo`, `until`. Записи с `"draft": true` видны только в `npm run dev`.
- Отзывы: `src/data/reviews.json`. Примеры с `"placeholder": true` на боевом сайте не показываются;
  блок «Отзывы» появляется, когда настоящих отзывов 3 и больше. Рейтинг — поля `rating` и `count`.
